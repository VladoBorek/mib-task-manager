# PV168 Project: MIB-Task-Manager
MIB Task Manager is a Java-SWING-based desktop application developed as part of a team project.
The application is used for managing tasks, logging work time, and monitoring activity.

## Features
- Creation and management of tasks with deadlines, descriptions, and categories
- Assignment of tasks to employees or departments
- Logging and comparison of allocated vs. actual time
- Visualization of completion rates and overdue tasks
- Task filtering, search, and sorting capabilities
- Task templates for repetitive workflows
- Import and export of task data (JSON)
- Automatic recalculation of statistics and summaries
- Option to use different time units
